# JenkinsIntegration

This is a simple Java project.

The project name "JenkinsIntegration" suggests that it might be used as a sample or test project for integrating with a Jenkins CI/CD pipeline.

## Functionality

The project contains a single Java class, `First.java`, which has a `main` method that prints the string "this change 1" to the standard output.

## How to Compile and Run

1.  **Compile:**
    ```bash
    javac src/First.java -d bin
    ```
2.  **Run:**
    ```bash
    java -cp bin First
    ```

This will execute the `main` method in `First.java`, and you will see "this change 1" printed to your console.
